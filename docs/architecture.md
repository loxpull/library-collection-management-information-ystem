# 5. Архитектурная схема

Для проекта предлагается клиент-серверная архитектура с модульным серверным приложением.

```text
                         ┌────────────────────┐
                         │     WPF-клиент     │
                         └─────────┬──────────┘
                                   │
                                  HTTP
                                   │
                                   ▼
                         ┌────────────────────┐
                         │    FastAPI Host    │
                         │     REST API       │
                         └─────────┬──────────┘
                                   │
          ┌────────────────────────┼─────────────────────┐
          │             │          │          │          │
          ▼             ▼          ▼          ▼          ▼
   ┌────────────┐ ┌───────────┐ ┌───────────┐ ┌──────────┐ ┌────────────┐
   │ BookModule │ │ CopyModule│ │ReaderModule│ │LoanModule│ │ReportModule│
   └──────┬─────┘ └─────┬─────┘ └─────┬─────┘ └────┬─────┘ └──────┬─────┘
          │             │             │            │              │
          └─────────────┴─────────────┴────────────┴──────────────┘
                                   │
                                   ▼
                         ┌────────────────────┐
                         │     PostgreSQL     │
                         │      Database      │
                         └────────────────────┘
```

Центральным модулем бизнес-процесса выдачи является `LoanModule`.

При оформлении выдачи он:

1. получает запрос от WPF-клиента;
2. проверяет существование читателя;
3. проверяет допустимость выдачи читателю;
4. запрашивает сведения об экземпляре;
5. проверяет доступность экземпляра;
6. создает запись о выдаче;
7. сохраняет данные в базе;
8. возвращает клиенту результат операции.

При возврате книги модуль фиксирует дату возврата и обновляет состояние экземпляра.

Проверка доступности и сохранение выдачи должны выполняться согласованно, чтобы один экземпляр нельзя было одновременно выдать нескольким читателям.

Архитектура описывает предполагаемое устройство системы. Реальные компоненты необходимо сверить с фактической реализацией проекта.
