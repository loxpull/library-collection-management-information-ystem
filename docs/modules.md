# 4. Перечень модулей системы

На стороне серверного API выделены основные функциональные модули.

| Модуль | Ответственность |
|---|---|
| `BookModule` | Управление каталогом книг |
| `CopyModule` | Учет экземпляров и их доступности |
| `ReaderModule` | Регистрация и учет читателей |
| `LoanModule` | Выдача, возврат и история операций |
| `ReportModule` | Формирование отчетов |
| `AuthModule` | Авторизация и управление доступом |

Точка входа `FastAPI Host` принимает HTTP-запросы от WPF-клиента и передает их соответствующим модулям.

## 4.1. BookModule

Отвечает за работу с каталогом книг.

Основные функции:

- добавление книги;
- редактирование библиографических сведений;
- поиск книг;
- фильтрация каталога;
- просмотр карточки книги;
- хранение сведений об авторах, издательстве и годе издания.

## 4.2. CopyModule

Отвечает за учет отдельных экземпляров книг.

Основные функции:

- добавление экземпляра;
- назначение инвентарного номера;
- изменение состояния экземпляра;
- проверка доступности;
- просмотр экземпляров выбранной книги.

Пример состояний экземпляра:

```text
Available
Issued
Reserved
Lost
Repair
```

## 4.3. ReaderModule

Отвечает за работу с читателями.

Основные функции:

- регистрация читателя;
- редактирование личных и контактных данных;
- поиск по ФИО;
- поиск по номеру читательского билета;
- просмотр истории выдач;
- проверка статуса читателя перед выдачей.

Пример состояний читателя:

```text
Active
Blocked
```

## 4.4. LoanModule

Отвечает за оформление выдачи и возврата книг.

Основные функции:

- регистрация выдачи экземпляра;
- назначение плановой даты возврата;
- регистрация фактического возврата;
- проверка доступности экземпляра;
- предотвращение повторной выдачи уже выданного экземпляра;
- хранение истории операций.

Пример состояний выдачи:

```text
Active
Returned
Overdue
Cancelled
```

Просрочка может определяться сравнением текущей даты с плановой датой возврата.

## 4.5. ReportModule

Отвечает за формирование отчетов.

Основные функции:

- подсчет книг и экземпляров в фонде;
- получение списка выданных книг;
- формирование списка просроченных возвратов;
- статистика выдач за период;
- формирование сводных отчетов.

## 4.6. AuthModule

Отвечает за управление доступом пользователей системы.

Основные функции:

- проверка учетных данных;
- определение роли сотрудника;
- ограничение доступа к административным функциям.

Модуль включается в фактическую реализацию, если авторизация предусмотрена проектом.
